https://rss.laro.dev/btc-usd.xml

Feed RSS con el precio actual del Bitcoin en dólares americanos (USD)
Se actualiza cada minuto. Precio obtenido gracias a CoinGecko.

Permite añadir un parámetro a la URL para obtener la hora local. Diferencia con UTC (numérico) o nombres de zonas horarias IANA. Ejemplos:

- https://rss.laro.dev/btc-usd.xml?tz=Europe/Madrid
- https://rss.laro.dev/btc-usd.xml?tz=-6
